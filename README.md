# Семейное исследование: Дьячковы и Диевы

Статический сайт с материалами исследования. Точка входа — `index.html` (меню со ссылками на все экраны).

| Страница | Что внутри |
|---|---|
| `index.html` | меню: ссылки на все экраны и внешние базы |
| `report.html` | полный отчёт: что установлено, что опровергнуто, план |
| `tree.html` | древо Дьячковых починка Шелемети, 1811–1899 |
| `search-plan.html` | план поиска: вопрос → документ → шифр |
| `links-1893.html` | подборка дел ГАПК по годам для метрики 1892–1894 |
| `reading-guide.html` | как читать сканы метрик: страницы дел, что искать |

Опубликовано через GitHub Pages. В публичной версии не публикуются имена ныне живущих.
